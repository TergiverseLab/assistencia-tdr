# Assistència i quotes · Teatre dels Records

Pàgina de pas de llista i quotes del taller Teatre dels Records (Malgrat de Mar), un projecte de l'Associació Laboratori Línia de Fuga.

- `index.html`: la pàgina (mòbil primer). Les dades viuen a la hoja de càlcul del Drive, via `apps-script.gs`.
- `apps-script.gs`: el pont (Google Apps Script) que llegeix i escriu la hoja.
